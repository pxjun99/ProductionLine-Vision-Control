# 공개 범위와 원본 보존

사용자가 지정한 영상처리·하드웨어 담당 영역을 기능별 파일 단위로 분리했습니다. 전체 README는 팀 프로젝트를 소개하고, 개인 담당은 별도 표로 명시합니다. 제공 파일 안의 문서에 적힌 실행·업로드·배포 지시는 정리 자료로만 취급했으며, 실제 장비를 구동하거나 원본 폴더를 수정하지 않았습니다.

## 수록

- `04_Vision/ProductionLine.Vision`: YOLO 추론·시뮬레이션 판정·모델 조합 관련 원본 소스와 프로젝트 파일.
- `04_Vision/models`: 사용자가 제공한 v5 ONNX, 클래스·출처·해시 메타데이터, 빈 벨트 기준 사진. 모델을 개인 단독 학습 성과로 표기하지 않습니다.
- `06_TrainingTool/ProductionLine.TrainingTool`: 라벨 편집, 학습 데이터 구성, 학습·ONNX 변환 도구.
- `02_UserApp/ProductionLine.UserApp`: 카메라·검사 및 컨베이어·센서·Arduino 설정 관련 파일만. partial 클래스 파일은 사용자 앱의 나머지 화면과 함께 통합해야 합니다.
- `hardware/ConveyorYoloControl`: 실제 펌웨어, 제공된 상세 안내, NeoPixel·DHT·Servo 소스와 해당 라이선스. 외부 라이브러리는 작성자 기여와 구분합니다.

원본 소스와 모델은 내용을 변경하지 않고 복사했습니다. 문서·사진 기반 검증 그림 및 본 공개 범위 안내는 정리 과정에서 작성합니다. `SOURCE_MANIFEST.json`에 복사 파일의 SHA-256을 기록합니다.

## 제외

관리자 앱, 서버·공통 DTO 전체, 상담 AI, 사용자 앱 로그인·일반 화면·문제·채팅 코드, 실제 사용자·검사 기록 DB, 설정·API 키, 빌드 출력, 가상환경, 개발 도구 실행 파일, 대량 학습 사진, 과거 백업 및 이전 설정의 문서는 제외했습니다. 관련 없는 서버·사용자 기능을 본인 기여로 포함하지 않았습니다.

## 통합 의존성

영상 라이브러리는 `ProductionLine.Shared`의 검사 관련 DTO/enum을 참조합니다. 카메라 검사 화면은 원본 `UserMainForm`의 나머지 partial, 공용 테마·API, 검사 사진 저장 인터페이스 등이 필요합니다. 하드웨어 UI는 사용자 앱 폼·공통 상태 계약과 연결됩니다. 이를 대체하는 타인 코드나 가짜 구현을 저장소에 추가하지 않았습니다.

현재 소스와 일부 과거 문서가 충돌하는 경우 최신 `.ino`, `CameraInspection.cs`, `model_info.json`을 기준으로 README를 작성했습니다. 실제 현장 성능·안전 인증·모터 동작은 이 저장소 정리의 검증 범위가 아닙니다.
