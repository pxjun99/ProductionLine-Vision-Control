## 하드웨어 모의 검사 범위

기존 C++ 호스트 테스트를 최신 DHT 호출 규격과 Arduino 경보 함수에 맞춘 모의 환경에서 실행했습니다. 시작 시 정지, V7 응답, 서보 예약·중복 거부, 55° 동작·복귀, NC 접점 정지 잠금·수동 해제, 통신 타임아웃 정지 등 테스트 앞부분은 통과했습니다.

기존 테스트는 센서 읽기에 실패하면 즉시 null을 반환할 것으로 기대하지만, 현재 펌웨어는 일시적 실패 때 마지막 유효값을 유지하도록 변경되어 해당 항목에서 중단됐습니다. 따라서 기존 테스트 전체가 통과했다고 기록하지 않았습니다. 모의 환경의 함수 대체는 검증용 폴더에만 적용했고 공개한 펌웨어는 원본을 유지했습니다.
